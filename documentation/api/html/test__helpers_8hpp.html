Detailed Description

Minimal header-only test framework shared by every Group 23 test program.

Author
Kyeyune Praise Pauline (Member 8)

Each test program includes this header, records results with check() and the expect_* helpers, and returns test::finish() from main(). The exit code is 0 when every check passed and 1 otherwise, which is what ctest and tests/run_all_tests.sh look at.

Plain C++17 with no external dependencies. It does not rely on assert(), so the checks run identically in Debug and Release builds.

#include "test_helpers.hpp"
int main()
{
test::check("1 + 1 is 2", 1 + 1 == 2);
test::expect_throw<std::invalid_argument>("bad n throws", [] { throw std::invalid_argument("n"); });
return test::finish("Example");
}
