Detailed Description

Unit tests for numcomp::AdvancedRootFinder (Secant and Fixed-Point Iteration).

Author
Bakalu Valeria (Member 4)

Covers normal use, edge cases and invalid input. Each check prints [PASS] or [FAIL]; the program returns 0 only if every check passed (see test_helpers.hpp).
