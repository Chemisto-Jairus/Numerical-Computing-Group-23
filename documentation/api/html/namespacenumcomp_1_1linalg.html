Solves a tridiagonal system with the Thomas algorithm in O(m) operations.

Row k of the system is lower[k] x[k-1] + diag[k] x[k] + upper[k] x[k+1] = rhs[k], where lower[0] and upper[m-1] are ignored. The forward sweep removes the sub-diagonal; back substitution then finds x from the last row upwards. No pivoting is done, which is safe for the diagonally dominant systems built by CubicSpline and FiniteDifferenceSolver.

The four vectors are taken by value because the sweep overwrites them.
