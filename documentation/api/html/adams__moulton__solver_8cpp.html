Detailed Description

Implementation of numcomp::AdamsMoultonSolver (AM2 and AM4).

Author
Muwanguzi Samuel (Member 7)

Both formulas have the form y_(n+1) = known + beta h f(t_(n+1), y_(n+1)). solve_corrector() finds y_(n+1) for either of them, and ode::run_multistep() provides the starting values, stored slopes and input checks.
