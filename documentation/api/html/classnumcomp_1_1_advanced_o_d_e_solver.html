Detailed Description

Solves first-order initial value problems dy/dt = f(t, y), y(t0) = y0, with explicit Runge-Kutta methods.

  • RK3 (Kutta's third-order method): three slopes per step, error ~ h^3.
  • RK4 (classic fourth-order method): four slopes per step, error ~ h^4.

Both march from t0 to t_end with a fixed step h and end exactly at t_end. The stepping loop is shared with BasicODESolver (see src/internal/ode_stepper.hpp).

The class is stateless.

numcomp::AdvancedODESolver solver;
auto curve = solver.rk4([](double t, double y) { return -2.0 * y; }, 0.0, 1.0, 1.0, 0.1);
double y_end = curve.back().second; // close to e^-2 = 0.135335

Solves dy/dt = f(t, y) with the classic fourth-order Runge-Kutta method.

k1 = f(t, y), k2 = f(t + h/2, y + h k1/2), k3 = f(t + h/2, y + h k2/2), k4 = f(t + h, y + h k3); y_(k+1) = y_k + h/6 (k1 + 2 k2 + 2 k3 + k4).

Parameters

t0Start time.
y0Initial value y(t0).
t_endEnd time. Must be greater than t0.
hStep size. Must be > 0.
Returns
The solution curve as (t, y) pairs, from (t0, y0) to t = t_end.
Exceptions

Solves dy/dt = f(t, y) with Kutta's third-order Runge-Kutta method.

k1 = f(t, y), k2 = f(t + h/2, y + h k1/2), k3 = f(t + h, y - h k1 + 2 h k2); y_(k+1) = y_k + h/6 (k1 + 4 k2 + k3).
