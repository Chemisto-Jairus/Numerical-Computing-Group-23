Detailed Description

Internal time-marching loop shared by the Adams-Bashforth and Adams-Moulton methods.

Author
Chemisto Jairus (Member 1)

A linear multistep method computes the next value of y from the slopes f(t, y) at several earlier points. Every such method needs the same surrounding work: input checks, a one-step method to create the first few points (the "starting values"), a record of the slopes, a shortened final step and an exact landing on t_end. run_multistep() does all of it; each method only supplies its formula as a MultistepRule. Not part of the public API (lives in src/internal/).
