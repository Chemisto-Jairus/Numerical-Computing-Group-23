Detailed Description

Everything in the Group 23 numerical computing library.

The library is split into fifteen stateless classes covering root finding, interpolation and Chebyshev approximation, numerical differentiation, integration, initial value problems (one-step, multistep and adaptive ODE solvers), boundary value problems and linear systems (direct and iterative). Every class has a default constructor and only public member functions. Invalid input is reported with standard exceptions:

  • std::invalid_argument: a parameter is outside its allowed range.
  • std::out_of_range: an interpolation point lies outside the data.
  • std::runtime_error: the method itself fails (no convergence, singular or non-positive-definite matrix, a result that is not a finite number).

double numcomp::solve_corrector ( const ode::ODEFunction & f,
double t_next,
double known,
double beta_h,
double guess )
static

Solves y = known + beta_h f(t_next, y) for y by fixed-point iteration.

Starts from guess and repeats y = known + beta_h f(t_next, y) until two successive values agree to about 1e-12 relative to |y|.

Parameters
fRight-hand side f(t, y).
t_nextTime of the new point, t_(n+1).
knownThe part of the formula that does not depend on y_(n+1).
beta_hWeight of f_(n+1) multiplied by h.
guessStarting value (the predictor).
Returns
y_(n+1).
Exceptions
std::runtime_errorIf the iteration does not converge within MAX_CORRECTOR_ITERATIONS, or produces a value that is not finite.
