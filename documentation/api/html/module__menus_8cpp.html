◆ run_safely()

template<typename Code>
void app::run_safely ( Code code)
static

Runs one calculation and turns any library exception into a message.

The handlers are ordered from the most specific exception type to the most general, and app::ui::InputEnded is not caught here, so ending the input still leaves the app.

Template Parameters
CodeAny callable taking no arguments.
Parameters
codeThe calculation to run.
