Detailed Description

Internal input-validation helpers shared by all library modules.

Author
Chemisto Jairus (Member 1)

This header lives in src/internal/, not in include/, so it is not part of the public API. Library source files include it as "internal/input_checks.hpp". Each check is defined once here and reused by every method that needs it, so the rules and the error messages are identical across the library.
