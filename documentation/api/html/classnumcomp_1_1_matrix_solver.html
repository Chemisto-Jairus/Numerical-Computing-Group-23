Detailed Description

Solves square linear systems A x = b.

  • gaussian_elimination(): reduces [A | b] to upper triangular form, then back-substitutes.
  • lu_solve(): factorises the row-swapped A as L U (Doolittle form, 1s on the diagonal of L), then solves L y = b and U x = y.

Both use partial pivoting: at each column the row with the largest absolute entry is moved to the pivot position. This avoids dividing by zero and keeps rounding errors small. Both cost O(n^3) operations and are meant for small, dense systems.

A matrix is a vector of rows: A[i][j] is row i, column j. The inputs are taken by const reference and copied internally, so the caller's A and b are never modified. The class is stateless.

numcomp::MatrixSolver solver;
std::vector<std::vector<double>> A = {{2, 1}, {1, 3}};
std::vector<double> b = {5, 10};
std::vector<double> x = solver.gaussian_elimination(A, b); // {1, 3}

Solves A x = b with LU decomposition (Doolittle) and partial pivoting.

Builds P A = L U, applies the same row swaps P to b, then solves L y = P b by forward substitution and U x = y by back substitution.
