Detailed Description

Shared output and error-handling helpers for the example programs in examples/.

Author
Nabakooza Bridget Maria (Member 9)

Every example prints a title, groups its work into sections, and shows results next to the exact answer where one is known. Each section runs inside demo::section(), which catches any exception, so one failing section cannot stop the rest of the demo. demo::finish() returns the exit code: 0 when every section completed, 1 otherwise.

#include "example_helpers.hpp"
int main()
{
demo::title("Bisection", "Root of x^2 - 2");
demo::section("Square root of 2", [] {
demo::compare("root", 1.41421356, std::sqrt(2.0));
});
return demo::finish();
}
