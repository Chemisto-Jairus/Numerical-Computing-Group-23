Detailed Description

Solves dy/dt = f(t, y), y(t0) = y0, with the explicit Adams-Bashforth methods.

A one-step method such as RK4 throws away its slopes after every step. Adams-Bashforth keeps the slopes f_k = f(t_k, y_k) of the last few points and fits a polynomial through them, so every new step needs only one new evaluation of f:

  • ab2(): y_(n+1) = y_n + h/2 (3 f_n - f_(n-1)), error ~ h^2.
  • ab4(): y_(n+1) = y_n + h/24 (55 f_n - 59 f_(n-1) + 37 f_(n-2) - 9 f_(n-3)), error ~ h^4.

The missing earlier points at the start are produced with RK4, and a final step shorter than h also uses RK4 (see src/internal/multistep.hpp).

The class is stateless.

numcomp::AdamsBashforthSolver ab;
auto curve = ab.ab4([](double t, double y) { return -2.0 * y; }, 0.0, 1.0, 1.0, 0.05);
double y_end = curve.back().second; // close to e^-2 = 0.135335
