Detailed Description

One interactive menu per topic of the library.

Author
Nabakooza Bridget Maria (Member 9)

Every menu follows the same flow:

  1. choose a method (or "compare all methods");
  2. choose a preset problem from the catalog, or type your own;
  3. confirm or change the suggested parameters (Enter keeps the default);
  4. read the result next to the exact answer and its error. Each calculation runs inside a handler that reports invalid input or a failed method and returns to the menu, so the app never stops on an error.
