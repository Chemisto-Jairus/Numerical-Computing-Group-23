Detailed Description

Solves first-order initial value problems dy/dt = f(t, y), y(t0) = y0.

  • Euler: one slope per step, global error ~ h (first order).
  • Heun (improved Euler / explicit trapezoid): two slopes per step, error ~ h^2.

Both march from t0 to t_end with a fixed step h. The last step is shortened when needed so the curve ends exactly at t_end. The stepping loop itself is shared with AdvancedODESolver (see src/internal/ode_stepper.hpp).

The class is stateless.

numcomp::BasicODESolver solver;
auto curve = solver.heun([](double t, double y) { return y; }, 0.0, 1.0, 1.0, 0.01);
double y_end = curve.back().second; // close to e = 2.71828

Solves dy/dt = f(t, y) with the explicit Euler method.

One step: y_(k+1) = y_k + h f(t_k, y_k).

Solves dy/dt = f(t, y) with Heun's method (predictor-corrector).

Predictor: k1 = f(t, y). Corrector: k2 = f(t + h, y + h k1). Step: y_(k+1) = y_k + h/2 (k1 + k2).
