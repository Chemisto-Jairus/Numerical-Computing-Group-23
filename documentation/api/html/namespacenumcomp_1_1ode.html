◆ run_multistep()

std::vector< std::pair< double, double > > numcomp::ode::run_multistep ( const ODEFunction & f,
double t0,
double y0,
double t_end,
double h,
int steps,
MultistepRule rule )

Integrates dy/dt = f(t, y) from t0 to t_end with a multistep rule.

The first (steps - 1) steps use the classic fourth-order Runge-Kutta method (AdvancedODESolver::rk4), because a method that needs steps earlier slopes cannot start from y0 alone. RK4 is also used for a final step that is shorter than h, because the multistep formulas assume equally spaced points. Every other step uses rule. f is evaluated once per point and the value is stored, so an explicit multistep step costs a single new evaluation of f.

StepRule step )

Integrates dy/dt = f(t, y) from t0 to t_end by repeating a step rule.

The final step is shortened when (t_end - t0) is not a multiple of h, and the last time value is set to exactly t_end.
