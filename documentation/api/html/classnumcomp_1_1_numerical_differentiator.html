Detailed Description

Approximates derivatives of a function from a few of its values.

Every formula replaces the limit in the definition of the derivative with a small, fixed step h:

  • forward_difference() and backward_difference(): one-sided, error ~ h.
  • central_difference(): symmetric, error ~ h^2.
  • second_derivative(): symmetric formula for f''(x), error ~ h^2.
  • richardson_extrapolation(): combines two central differences, error ~ h^4.

Choosing h is a balance: a large h gives a large truncation error, and a very small h loses digits to rounding, because f(x + h) and f(x - h) become almost equal. h around 1e-5 suits the first-derivative formulas in double precision.

The class is stateless.

numcomp::NumericalDifferentiator diff;
double d = diff.central_difference([](double x) { return x * x * x; }, 2.0, 1e-4); // close to 12

double numcomp::NumericalDifferentiator::forward_difference ( std::function< double(double)> f,
double x,
double h )

Forward difference: f'(x) ~ (f(x + h) - f(x)) / h.

Taylor's theorem gives an error of (h/2) f''(xi), so the method is first order. It only needs f at x and to the right of x, which is useful at a left boundary.

Central difference: f'(x) ~ (f(x + h) - f(x - h)) / (2h).

The h^2 terms of the two Taylor series cancel, leaving an error of (h^2/6) f'''(xi): second order for the same two function evaluations.

double x,

Richardson extrapolation of the central difference: error ~ h^4.

With D(h) = central_difference(f, x, h), the leading error terms of D(h) and D(h/2) cancel in (4 D(h/2) - D(h)) / 3. This is the same idea that Romberg integration applies to the trapezoidal rule.

xPoint where the derivative is wanted.
hStep size of the coarser central difference. Must be > 0.

The approximation of f'(x).
