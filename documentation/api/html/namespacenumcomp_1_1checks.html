void numcomp::checks::check_tolerance ( double tol,
int max_iter )

Validates the stopping settings of an iterative root finder.

Used by bisection, newton_raphson, secant_method, fixed_point_iteration, the conjugate gradient solver and the Runge-Kutta-Fehlberg solver. The test is written as !(tol > 0) so that NaN is rejected as well.

Parameters
tolConvergence tolerance. Must be > 0.
max_iterIteration limit. Must be > 0.
Exceptions
std::invalid_argumentIf tol <= 0, tol is NaN, or max_iter <= 0.

◆ find_interval()

std::size_t numcomp::checks::find_interval ( double x,
const std::vector< double > & x_vals )

Finds the interval of the data that contains x.

Used by Interpolator::linear_interpolate and CubicSpline::interpolate. Assumes check_data_points() has already succeeded. The search is a binary search, so it needs about log2(n) comparisons for n data points.

Parameters
xQuery point.
x_valsStrictly increasing x values.
Returns
The index i with x_vals[i] <= x <= x_vals[i + 1].
Exceptions
std::out_of_rangeIf x is outside [x_vals.front(), x_vals.back()].

void numcomp::checks::check_ode_inputs ( double t0,
double t_end,
double h )

Validates the time interval and step size of a fixed-step ODE solver.

Used by ode::run_fixed_steps (euler, heun, rk3, rk4), ode::run_multistep (the Adams-Bashforth and Adams-Moulton methods) and the Runge-Kutta-Fehlberg solver.

Parameters
t0Start time.
t_endEnd time. Must be greater than t0.
hStep size. Must be > 0.
Exceptions
std::invalid_argumentIf h <= 0, t_end <= t0 (either may be NaN), or (t_end - t0) / h exceeds MAX_POINTS.

void numcomp::checks::check_finite_result ( double value)

Confirms that a computed value is a finite number.

Used after a calculation whose result depends on the user's function: numerical derivatives, the adaptive and multistep ODE solvers and the finite difference boundary value solver. A NaN or infinite value means that f overflowed or was evaluated at a singularity.

Parameters

Exceptions
