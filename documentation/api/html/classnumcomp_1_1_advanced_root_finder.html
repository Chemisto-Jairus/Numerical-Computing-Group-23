Detailed Description

Root finding methods that do not need the derivative f'(x).

  • Secant method: like Newton-Raphson, but the tangent is replaced by the line through the last two points. Converges with order about 1.618.
  • Fixed-Point Iteration: solves x = g(x) by repeating x_new = g(x). Converges when |g'(x)| < 1 near the answer.

The class is stateless: one object can be reused for any number of calls.

numcomp::AdvancedRootFinder finder;
double r = finder.secant_method([](double x) { return x * x - 4.0; }, 1.0, 3.0, 1e-10, 100); // 2
double p = finder.fixed_point_iteration([](double x) { return std::cos(x); }, 1.0, 1e-12, 1000); // 0.739085...

Finds a root of f from two starting guesses, without a derivative.

The next guess is where the straight line through (x0, f(x0)) and (x1, f(x1)) crosses zero: x2 = x1 - f(x1) (x1 - x0) / (f(x1) - f(x0)).

Parameters
fThe function whose root is wanted.
x0First starting guess.
x1Second starting guess.
tolStop when two successive guesses differ by less than tol. Must be > 0.
max_iterMaximum number of steps. Must be > 0.
Returns
An x with f(x) close to 0.
Exceptions
std::invalid_argumentIf tol <= 0 or is NaN, or max_iter <= 0.
std::runtime_errorIf |f(x1) - f(x0)| < 1e-12 (the secant line is flat), or no root is found within max_iter steps.

Solves x = g(x) by repeating x_new = g(x).

To find a root of f, rewrite f(x) = 0 as x = g(x). The iteration converges when g is a contraction near the answer (|g'(x)| < 1).

Parameters
gThe function in x = g(x).
x0Starting guess.
tolStop when two successive values differ by less than tol. Must be > 0.
max_iterMaximum number of steps. Must be > 0.
Returns
The fixed point x, where x = g(x).
Exceptions
std::invalid_argumentIf tol <= 0 or is NaN, or max_iter <= 0.
std::runtime_errorIf no fixed point is found within max_iter steps.
