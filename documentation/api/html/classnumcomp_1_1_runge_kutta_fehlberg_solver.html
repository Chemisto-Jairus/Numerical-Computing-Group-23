Detailed Description

Solves dy/dt = f(t, y), y(t0) = y0, choosing the step size automatically.

Each RKF45 step evaluates six slopes and combines them in two ways: a fourth-order and a fifth-order estimate of y(t + h). Their difference estimates the error of the step. A step whose error per unit time is within the tolerance is accepted; otherwise it is repeated with a smaller h. After every step h is rescaled by 0.84 (tol / R)^(1/4), where R is the estimated error per unit time, so h grows where the solution is smooth and shrinks where it changes quickly.

This is the same "estimate the error, then refine" idea that Romberg integration uses, applied to ODEs.

The class is stateless.

numcomp::RungeKuttaFehlbergSolver rkf;
auto curve = rkf.rkf45([](double t, double y) { return -2.0 * y; }, 0.0, 1.0, 1.0, 0.1, 1e-8);
double y_end = curve.back().second; // close to e^-2 = 0.135335

Solves dy/dt = f(t, y) from t0 to t_end with adaptive RKF45 steps.

k1 = h f(t, y), ..., k6 = h f(t + h/2, ...) (Fehlberg's coefficients). y4 = y + 25/216 k1 + 1408/2565 k3 + 2197/4104 k4 - 1/5 k5 (order 4) is kept; y5 = y + 16/135 k1 + 6656/12825 k3 + 28561/56430 k4 - 9/50 k5 + 2/55 k6 (order 5) is only used for the error estimate R = |y5 - y4| / h. The step is accepted when R <= tol.

Parameters
fRight-hand side f(t, y).
t0Start time.
y0Initial value y(t0).
t_endEnd time. Must be greater than t0.
h_initialFirst step size to try. Must be > 0.
tolAllowed error per unit time. Must be > 0.
Returns
The accepted points as (t, y) pairs, from (t0, y0) to t = t_end. The spacing of the points shows where the method needed small steps.
Exceptions
std::invalid_argumentIf h_initial <= 0, t_end <= t0, tol <= 0 (any of them may be NaN), or (t_end - t0) / h_initial exceeds 1,000,000.
std::runtime_errorIf the step size has to shrink below about 1e-12 of t, more than 1,000,000 steps are needed, or the solution is not finite.
