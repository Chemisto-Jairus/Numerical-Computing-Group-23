Detailed Description

Solves A x = b iteratively when A is symmetric positive definite (SPD).

The conjugate gradient (CG) method improves a guess x step by step. Each step moves along a search direction that is "A-conjugate" to all earlier directions, so in exact arithmetic CG finishes in at most n steps for an n x n system. In practice it stops as soon as the residual r = b - A x is small: ||r|| <= tol * ||b||.

Each step needs one matrix-vector product and no row operations, so A is never changed. This makes CG the method of choice for large, sparse SPD systems (for example from finite differences), where Gaussian elimination would fill the matrix in.

The class is stateless.

numcomp::ConjugateGradientSolver cg;
std::vector<std::vector<double>> A = {{4, 1}, {1, 3}};
std::vector<double> x = cg.solve(A, {1, 2}, 1e-12, 100); // 1/11, 7/11

Solves A x = b with the conjugate gradient method from a given starting guess.

r_0 = b - A x_0, p_0 = r_0. For k = 0, 1, ...: alpha = (r.r) / (p.A p), x = x + alpha p, r = r - alpha A p, beta = (r_new.r_new) / (r.r), p = r + beta p. A good starting guess (for example the answer to a nearby problem) saves iterations.

Parameters
ASymmetric positive definite matrix, stored as a vector of rows.
bRight-hand side.
x0Starting guess, same size as b.
tolRelative residual tolerance. Must be > 0.
max_iterLargest number of iterations. Must be > 0.
Returns
The solution x.
Exceptions
std::invalid_argumentIf the sizes do not match, A is not symmetric, tol <= 0 (or NaN), or max_iter <= 0.
std::runtime_errorIf A turns out not to be positive definite, or the tolerance is not reached within max_iter iterations.
