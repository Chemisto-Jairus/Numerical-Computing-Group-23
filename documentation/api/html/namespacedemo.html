template<typename Code>
void demo::show_rejected ( const std::string & label,
Code code )

Shows that the library rejects an invalid call.

Runs code, expects an exception, and prints its message. This is part of the demonstration, so a caught exception is not a failure. If nothing is thrown, the section is counted as failed.

Template Parameters
CodeAny callable taking no arguments.
Parameters
