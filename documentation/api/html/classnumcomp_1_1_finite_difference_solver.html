Detailed Description

Solves y'' = p(x) y' + q(x) y + r(x) on [a, b] with y(a) = alpha, y(b) = beta.

Unlike an initial value problem, the conditions are given at both ends, so the solution cannot be marched forward from one side. The finite difference method instead places n + 1 equally spaced grid points x_i = a + i h, h = (b - a)/n, and replaces the derivatives at every inner point with central differences: y'' ~ (y_(i-1) - 2 y_i + y_(i+1)) / h^2 and y' ~ (y_(i+1) - y_(i-1)) / (2h). This gives one linear equation per inner point. Each equation links only three neighbours, so the system is tridiagonal and is solved in O(n) operations with the Thomas algorithm (shared with CubicSpline). The error is ~ h^2.

The system is guaranteed to be solvable when q(x) >= 0 on [a, b] and h |p(x)| / 2 < 1 (the matrix is then diagonally dominant).

The class is stateless.

numcomp::FiniteDifferenceSolver fd;
// y'' = -pi^2 sin(pi x), y(0) = y(1) = 0; the exact solution is y = sin(pi x)
const double pi = std::acos(-1.0);
auto grid = fd.poisson([=](double x) { return -pi * pi * std::sin(pi * x); }, 0.0, 1.0, 0.0, 0.0, 100);
// grid[50] is the point x = 0.5, where y is close to 1

Solves the linear boundary value problem y'' = p(x) y' + q(x) y + r(x).

Multiplying the difference equation at x_i by -h^2 gives -(1 + h p_i / 2) y_(i-1) + (2 + h^2 q_i) y_i - (1 - h p_i / 2) y_(i+1) = -h^2 r_i, for i = 1 .. n-1. The known boundary values y_0 = alpha and y_n = beta are moved to the right-hand side of the first and last equations.

qCoefficient of y.

aLeft end of the interval.
bRight end of the interval. Must be greater than a.

betaBoundary value y(b).

Exceptions

std::runtime_errorIf the tridiagonal system is singular, or p, q or r give values that are not finite numbers.

Solves the one-dimensional Poisson problem y'' = r(x), y(a) = alpha, y(b) = beta.

The special case p = q = 0 of linear_bvp(). It describes, for example, the deflection of a string under a load or the steady temperature in a rod with a heat source r(x).
