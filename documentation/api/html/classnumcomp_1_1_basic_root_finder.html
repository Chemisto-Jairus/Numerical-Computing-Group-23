Detailed Description

Finds a root of a function f, that is, an x with f(x) = 0.

Two classic methods are provided:

  • Bisection: very reliable, needs an interval where f changes sign, converges linearly.
  • Newton-Raphson: very fast near the root (quadratic convergence), needs f'(x).

The class is stateless: it stores no data, so one object can be reused for any number of calls.

numcomp::BasicRootFinder finder;
auto f = [](double x) { return x * x - 2.0; };
auto df = [](double x) { return 2.0 * x; };
double r1 = finder.bisection(f, 0.0, 2.0, 1e-10, 100); // 1.41421356...
double r2 = finder.newton_raphson(f, df, 1.0, 1e-12, 50); // 1.41421356...

double a,

Finds a root of f inside [a, b] by repeatedly halving the interval.

f(a) and f(b) must have opposite signs, so by the intermediate value theorem a root lies between them. Each step keeps the half in which the sign still changes. After k steps the interval width is (b - a) / 2^k. The two ends may be given in either order.

Parameters
fThe function whose root is wanted.
aOne end of the interval.
bThe other end of the interval.
tolStop when |f(c)| < tol or the half-width is below tol. Must be > 0.
max_iterMaximum number of halvings. Must be > 0.
Returns
An x with f(x) close to 0.
Exceptions
std::invalid_argumentIf tol <= 0 or is NaN, max_iter <= 0, f(a) or f(b) is NaN, or f(a) and f(b) have the same sign.
std::runtime_errorIf no root is found within max_iter halvings.

Finds a root of f with Newton's iteration x_new = x - f(x) / f'(x).

Each step follows the tangent line at x down to the x-axis. Close to a simple root the number of correct digits roughly doubles every step. A poor starting guess or f'(x) close to 0 can stop it.

Parameters
fThe function whose root is wanted.
dfThe derivative f'(x).
x0Starting guess.
tolStop when two successive guesses differ by less than tol. Must be > 0.
max_iterMaximum number of steps. Must be > 0.
Returns
An x with f(x) close to 0.
Exceptions
std::invalid_argumentIf tol <= 0 or is NaN, or max_iter <= 0.
std::runtime_errorIf |f'(x)| < 1e-12 at some step, or no root is found within max_iter steps.
